# WebFace Enterprise / DNL MARKET

Веб-приложение для электронной торговой площадки (ETP) - платформа для дистрибуции расходных материалов

## Описание

WebFace Enterprise - это интернет-магазин B2B, интегрированный с внешней системой электронной торговой площадки через REST API. Платформа позволяет клиентам просматривать каталог товаров, формировать заказы, управлять корзиной и работать с контрагентами

## Технологический стек

- **Backend:** Laravel 12, PHP 8.2+
- **База данных:** SQLite
- **Frontend:** Tailwind CSS 4, Vite
- **Дополнительно:** 
  - QR-коды (endroid/qr-code)
  - Email-уведомления
  - Защита от ботов (AntibotService)

## Основной функционал

### Публичные страницы
- Главная страница с популярными и новыми товарами
- О компании
- Контакты
- Политика конфиденциальности
- Отправка сообщений

### Аутентификация
- Регистрация пользователей
- Вход в систему
- Восстановление доступа
- Личный кабинет

### Каталог и товары
- Древовидная структура каталогов
- Просмотр товаров (офферов) с вариантами
- Фильтрация и сортировка
- Избранное
- Сравнение товаров
- Генерация QR-кодов

### Корзина и заказы
- Управление корзиной
- Формирование заказов
- История заказов
- Интеграция с внешней системой ETP

### Контрагенты
- Управление контрагентами (для авторизованных пользователей)
- Просмотр заказов по контрагентам

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
composer install
npm install
```

3. Настройте окружение:
```bash
cp .env.example .env
php artisan key:generate
```

4. Настройте базу данных в `.env`:
```
DB_CONNECTION=sqlite
```

5. Выполните миграции:
```bash
php artisan migrate
```

6. Настройте параметры ETP в `.env`:
```
ETP_DOMAIN=your-domain.com
ETP_BASE_NAME=1SWEB
ETP_API_PATH=api
ETP_LOGIN=your_login
ETP_PASSWORD=your_password
ETP_SSL=true
```

7. Запустите приложение:
```bash
# Разработка (запускает сервер, очереди, логи и Vite)
composer dev

# Или отдельно:
php artisan serve
npm run dev
```

## Структура проекта

- `app/Http/Controllers/` - контроллеры приложения
- `app/Services/` - сервисы (ExtensionService для работы с ETP API, QrService, AntibotService)
- `app/Mail/` - классы для отправки email
- `resources/views/` - Blade-шаблоны
- `routes/web.php` - маршруты приложения
- `config/enterprice.php` - конфигурация интеграции с ETP

## Основные сервисы

- **ExtensionService** - интеграция с внешним ETP API (каталоги, товары, заказы, пользователи)
- **QrService** - генерация QR-кодов
- **AntibotService** - защита от автоматических запросов

## Email-уведомления

Приложение отправляет следующие типы писем:
- Регистрация пользователя
- Восстановление доступа
- Сообщения с сайта
- Уведомления о заказах
